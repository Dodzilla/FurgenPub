# Furgen H3 Video Tools

This package is the H3-only runtime used by `video_gen_v5`. It contains Furgen's
MiniMax H3 and general video utility nodes plus the four small MIT-licensed
workflow-wiring helpers still used by injected workflows.

KJNodes and VideoHelperSuite remain pinned upstream because they are GPL. VFI
also remains pinned upstream because its inspected revision has no usable
license grant.
